# Save PNG, SVG or PDF

Click "Export" in the toolbar:

- Scale: 1x, 2x or 4x.
- Width and Height: an exact size in pixels. Set one and the other follows the shape; set both and the PNG fits that box. The menu shows the final size before you save.
- "Text labels for wikis": labels as plain SVG text, for Azure DevOps and GitHub wikis.
- "Save PNG" and "Save SVG" open a save dialog next to the source file. "Copy PNG" and "Copy SVG code" use the clipboard.
- "Save PDF": every diagram of the file in one PDF with a title page.

"Export All Diagrams in Workspace" writes every diagram in the folder to SVG and/or PNG.

Exports use the background you picked in the toolbar: the editor color, white, transparent or a custom color.
