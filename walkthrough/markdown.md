# Diagrams in Markdown

Each ` ```mermaid ` block in a Markdown file gets two links above it:

- "Edit diagram" opens the block as its own small file next to a live preview. Save it, and the text goes back into the block. Undo in the Markdown file takes the change back.
- "Preview" shows that diagram with zoom and export.

The preview of a whole Markdown file lists every diagram, each with its own error line and export buttons. The "Mermaid Diagrams" view in the Explorer lists them too; click one to go there.

`mermaidViewer.codeLens` turns the links off.
